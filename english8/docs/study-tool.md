# 中英文学习工具说明

## 文件

第一次使用 Supabase 或需要部署到 GitHub Pages，请阅读 [cloud-sync-guide.md](cloud-sync-guide.md)，里面按新手步骤说明了注册、建项目、执行 SQL、配置邮箱登录和电脑手机同步。

- `study-tool.html`

这是一个单独的本地网页脚本，不需要安装依赖或启动服务器。输入一次 `英文 | 中文`，题库、三种默写练习、答题记录和错题复习共用同一份数据。题库可以带名称、备注和共享说明，方便多人之间传递和后续管理。

## 输入格式

每行一组，使用英文半角竖线 `|` 分隔：

```text
I think software testing is important. | 我认为软件测试很重要。
This module supports OBC testing. | 这个模块支持 OBC 测试。
```

中文内容中如果包含 `|`，程序会把第一个 `|` 当作分隔符，后面的内容仍归入中文。

## 练习类型

- `听英文默写英文`：播放英文，只填写听到的英文。
- `看中文默写英文`：显示中文，填写对应英文。
- `看英文默写中文`：显示英文，填写对应中文。

每条答题记录都会保留：题目、英文、中文、你的答案、正确答案、默写类型、自动判定、人工判定、得分和作答时间。

## 记录与错题

- 提交后会自动判定，通过或不通过都进入练习记录。
- 英文自动判定忽略大小写、常见标点、标点后的空格和缩写撇号差异；中文自动判定忽略常见标点和空格。
- “下一题自动提交”默认开启；点击“下一题”时，如果当前题还没有提交，会先提交当前答案再进入下一题。
- 可以在当前题目或历史记录中手动改为“通过 / 不通过”，并恢复默认判定。
- 同一练习轮次中每道题只保留一条记录；重做同一题时会覆盖原记录，默写类型不会额外产生第二条记录。
- 练习题目中提供“重做本题”，可在同一轮直接重新作答并覆盖原记录。
- 每条历史记录都可以移入回收箱；删除会同步更新统计、错题和导出内容。回收箱支持单条恢复、单条彻底删除和清空，恢复及永久删除状态都会同步到其他设备。
- “错题复习”按照“题目 + 默写类型”分别统计，避免同一句话在不同默写方向下互相覆盖。
- 错题复习会保留原默写类型；该题最新一次判定为通过后，会自动从当前错题中移除。
- 错题页支持按关键词和默写类型筛选，显示历史错误次数与已解决数量。
- 每道错题可以单独复习、读英文、读中文、复制题目或删除该错题记录，也可以按筛选结果批量复习。
- 点击“批量复习当前错题”后，会按筛选结果批量生成复习队列；每道题按最近一次做错时的默写类型进入，进入下一道时练习页会同步显示实际类型。
- 错题卡片前可以勾选；“复习已选”只显示勾选的错题和答案，“默写已选”只把勾选题加入默写队列，也可以直接默写当前筛选结果。
- 错题支持组合筛选：当前未解决或全部历史、指定第几轮、起止日期、默写类型、具体题目及关键词。
- 页面会自动保存到浏览器本地存储，刷新页面后题库和记录仍会恢复。
- 历史记录显示“记录编号”和“本轮题号”；不同练习轮次的第一题不会再看起来像同一条记录。
- 可以为题库填写名称和备注，导出文件会自动使用题库名称命名。
- 所有导出内容都会写入导出日期和时间；JSON 使用 `exportedAt`，TXT 会显示“导出时间”，文件名也带有时间戳。
- 默写中点击“退出默写”可以选择保存本轮已提交答案、放弃本轮答案，或继续默写。

## 导入与导出

- `导出题库 TXT`：导出可直接粘贴回输入框的 `英文 | 中文` 题库，适合打印或简单共享。
- `导出共享题库 JSON`：只导出题库名称、备注和题目，不包含个人答题记录，适合发给别人共同使用。
- `复制共享 JSON`：把共享题库 JSON 直接复制到剪贴板，适合粘贴到聊天、邮件或文档中。
- `导出完整备份 JSON`：导出题库、所有答题记录、错题状态和设置，推荐用于换电脑或长期备份。
- `导出记录 JSON/TXT`：只导出答题记录。
- `导出本轮 JSON/TXT`：只导出当前练习轮次；退出并保存后仍可导出最近保存的一轮。
- `导出全部 JSON/TXT`：导出所有练习轮次的记录。
- `导出错题 JSON/TXT`：只导出当前错题，包含题目、答案和默写类型。
- 错题页同样提供本轮错题和全部错题两种导出范围。
- `导入题库/备份`：支持题库 TXT、共享题库 JSON、完整备份 JSON、记录 JSON 和错题 JSON。
- 导入错题 JSON 或错题 TXT 时，会自动创建一个新的最新错题轮次，并保留每道题原来的默写类型。
- `合并导入`：保留当前内容并追加导入数据，重复题目和重复记录不会重复添加。
- `覆盖恢复`：用导入文件中的题库和记录替换当前数据，适合恢复完整备份。
- 导入后会先显示文件名、题目数量、答题记录数量、题库名称和导入方式；点击“确认导入”后才会写入。

共享题库 JSON 是多人共享的推荐格式；完整备份 JSON 是个人数据迁移的推荐格式。TXT 主要用于阅读、打印和重新导入题库；如果要保留答题记录、人工判定和默写类型，请使用 JSON。

## 使用步骤

1. 打开 `study-tool.html`。
2. 粘贴多行 `英文 | 中文`，点击“生成内容”。
3. 在“默写练习”中选择默写类型并开始练习。
4. 提交答案后查看自动判定，必要时手动修改通过或不通过。
5. 需要中途离开时点击“退出默写”，选择保存、放弃或继续。
6. 在“错题复习”中复习当前错题。
7. 在“数据管理”中检查题库统计，并选择共享题库或完整备份导出。
8. 导入文件后先检查预览，再选择合并或覆盖并确认导入。

## 兼容性

- 使用原生 HTML、CSS 和 JavaScript。
- 本地模式不依赖第三方库，支持直接双击本地 HTML 打开；云同步模式需要联网加载 Supabase。
- 语音朗读使用浏览器的 `speechSynthesis`；如果浏览器不支持，文字默写和记录功能仍可使用。
- 本地存储受浏览器隐私模式和浏览器策略影响，因此重要数据应定期导出完整备份。

## 电脑手机自动同步

网页默认使用本地保存；要在电脑和手机之间自动同步，需要配置 Supabase。

### Supabase 配置

1. 注册并创建 Supabase 项目。
2. 打开 Supabase 的 SQL Editor，执行同目录下的 `supabase-sync.sql`。
3. 在 Authentication 中启用 Email 登录。
4. 在 Project Settings / API 中复制 Project URL 和 `anon public` key。
5. 打开工具的“数据管理”，填入 URL 和 key，点击“保存云配置”。
6. 注册一个同步账号并登录。
7. 手机和电脑打开同一个网页，登录同一个同步账号即可自动同步。

Supabase URL 和 anon key 会自动保存在当前浏览器。需要自动回填同步账号和密码时，勾选“记住同步账号和密码”；密码仅保存在当前浏览器的本地存储中，不要在公用设备上启用。取消勾选会立即清除已保存的账号密码。

同步内容包括题库、题库名称和备注、答题记录、回收箱及记录生命周期、错题、默写类型、判定结果以及练习设置。首次登录时，云端数据会和当前设备数据合并；之后每次保存会自动上传，页面打开期间约每 30 秒检查一次云端更新。移入回收箱、恢复和彻底删除都会记录操作时间，防止其他设备上的旧云端快照覆盖最新状态。

部署到 GitHub Pages 时，必须同时上传 `study-tool.html` 和 `cloud-sync.js`。不要上传包含个人答题记录的完整备份 JSON，也不要把 Supabase `service_role` key 放进网页或仓库；网页中只使用 `anon public` key，并依赖 SQL 文件中的行级安全策略。

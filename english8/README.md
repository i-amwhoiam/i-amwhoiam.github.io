# 中英文学习工具

推荐入口：index.html。工具使用同一份 英文 | 中文 题库完成句库学习和三种默写练习，并保留答题记录与错题复习数据。

## 主要文件

- index.html：主入口页面，可直接双击打开。
- js/cloud-sync.js：可选的 Supabase 云同步模块。
- docs/supabase-sync.sql：Supabase 数据表和行级安全策略。
- docs/study-tool.md：详细使用说明、数据格式和导入导出说明。
- docs/cloud-sync-guide.md：Supabase 云同步配置说明。
- 1.html、4.html、combined.html：之前的旧版模块，保留作为参考。

## 功能

- 输入一次多行 英文 | 中文。
- 句库搜索、双语显示、英文朗读和中文朗读。
- 听英文默写英文、看中文默写英文、看英文默写中文。
- 自动判定，并可在当前题目或历史记录中手动改为通过 / 不通过。
- 默写中可以选择保存本轮、放弃本轮或继续练习。
- 同一轮每道题只保留一条记录，重做同一题会覆盖原记录，每条历史记录也可以单独删除。
- 练习中可以直接点击“重做本题”后覆盖本轮原记录。
- 自动保存题库、答题内容和错题。
- 错题按题目和默写类型保留，可单独复习。
- 错题支持关键词/默写类型筛选、错误次数统计、单题复习、朗读、复制和删除。
- 错题复习会优先沿用每道题最近一次做错时的默写类型。
- 题库可设置名称和备注，方便共享、分类和管理。
- 复制或导出共享题库 JSON、完整备份 JSON、题库 TXT、练习记录和错题。
- 练习记录和错题都可以按“本轮”或“全部”范围导出。
- 导出文件内容和文件名都带有日期时间，方便区分不同版本。
- 可选配置 Supabase，实现电脑和手机登录同一账号后的自动同步。
- 导入前预览文件信息，支持合并导入或覆盖恢复。
- 错题文件跨设备导入后会作为新的最新错题轮次，可按轮次和具体题目选择复习。

## 兼容性

第一次使用 Supabase 或想发布到 GitHub Pages，请先阅读 [docs/cloud-sync-guide.md](docs/cloud-sync-guide.md)。里面包含注册、创建项目、执行 supabase-sync.sql、配置 Email 登录、获取 URL 和公开 key、发布 GitHub Pages 以及常见故障排查。

- 原生 HTML / CSS / JavaScript。
- 本地模式不依赖第三方库，支持离线打开；云同步模式需要联网访问 Supabase。
- 语音朗读依赖浏览器 speechSynthesis；不支持语音的浏览器仍可使用文字默写和记录功能。
